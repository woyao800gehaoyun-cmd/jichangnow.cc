从拿到订阅链接，到成功连接

不同客户端界面会略有差别，但核心流程相同：购买套餐、复制订阅、导入客户端、更新配置、选择节点并开启系统代理。

六步完成配置

选择并安装客户端

Windows 和 macOS 可优先考虑图形化客户端；Android 选择支持订阅导入的兼容客户端；iPhone / iPad 常见选择为 Shadowrocket。只从官方页面下载。

购买套餐并复制订阅链接

登录机场用户中心，在订阅、仪表盘或一键订阅区域复制完整链接。订阅链接相当于访问凭证，不要发给其他人。

在客户端导入订阅

找到“订阅管理”“从 URL 导入”或“新建配置”，粘贴订阅链接并保存。首次导入后手动执行一次更新。

选择合适节点

先选择地理距离较近的香港、日本、新加坡等节点测试。延迟最低不等于一定最快，应结合网页、视频与自己的实际任务判断。

开启系统代理

普通使用可先选择规则模式，让国内网站直连、需要代理的请求走节点。全局模式会让更多流量经过代理，排查问题时再使用。

检查 IP 与连接状态

打开 IP 查询和测速工具，确认出口 IP 已变化。若无法连接，依次尝试更新订阅、切换节点、重启客户端和检查系统时间。

常见问题排查

!

订阅导入失败

确认链接没有多余空格、套餐仍在有效期、订阅未被重置。不要在浏览器或公开群聊中暴露订阅内容。

↻

节点全部超时

先更新订阅并切换网络测试；确认系统日期时间正确；退出其他代理、VPN 或安全软件后再排查冲突。

△

能连接但速度慢

切换不同地区节点，在晚高峰重新测试。测速前关闭云盘同步、系统更新和其他占用带宽的任务。
